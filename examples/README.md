# Examples

One worked configuration, in a field chosen because it is not yours: the point
is the shape, not the terms.

- **`shift-work-sleep.yaml`** — a clinical topic with a distinct population,
  showing every part of the config in use at once: a two-field query, precise
  phrases, exclusions, a watchlist, a tracked researcher, journals, tuned
  scoring weights, and pipeline tags.

Copy it to `config.yaml`, swap the terms for yours, and delete what you do not
need. Everything except `project.email` and `search` is optional.

A word on what an example can and cannot give you: the *structure* transfers,
the *terms* never do. A term list is only good relative to a particular set of
papers you have already judged, so a borrowed one is untested by definition.
`guide/search-method.md` covers how to test yours.
